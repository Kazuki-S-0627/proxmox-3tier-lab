## 証跡を追加するときのルール

- コマンド全文より、確認に必要な行だけを載せる
- 実IPは`<WEB01_IP>`、`<APP01_IP>`、`<DB01_IP>`などへ置換する
- ユーザー名、ホームディレクトリ、FQDN、MACアドレス、シリアル番号を削除する
- FortiGateのシリアル番号、ライセンス情報、管理者名を削除する
- スクリーンショットはブラウザ全体ではなく対象箇所だけを切り出す
- 「成功」の記載には、実行日、観点、期待結果、実結果を添える
