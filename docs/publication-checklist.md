# GitHub公開前チェックリスト

## 秘密情報

- [ ] パスワード、APIトークン、Cookie、セッションIDがない
- [ ] SSH秘密鍵、秘密鍵、証明書の秘密情報がない
- [ ] データベース接続文字列や認証情報がない
- [ ] `.env`、バックアップ、設定全量エクスポートがない
- [ ] Git履歴にも削除済み秘密情報が残っていない

## 個人情報・機器情報

- [ ] 氏名、メールアドレス、個人ユーザー名がない
- [ ] 自宅の実IP、実ホスト名、MACアドレスがない
- [ ] ProxmoxやFortiGateのシリアル番号、ライセンス情報がない
- [ ] ブラウザのタブ、ブックマーク、プロフィール画像が写っていない
- [ ] Notionのサイドバー、ワークスペース名、他ページ名が写っていない

## 内容の正確性

- [ ] ホームラボであり商用実務ではないと明記している
- [ ] 記録済み、公開用再構成、確認待ちを混同していない
- [ ] OS・製品バージョンを未確認のまま記載していない
- [ ] 動作確認していない経路を「成功」と書いていない
- [ ] 実ラボのアドレスがなく、RFC 5737文書用アドレス・loopback・伏せ字だけになっている

## 画像

- [ ] 対象部分だけに切り出している
- [ ] EXIFなどの位置・端末メタデータを削除している
- [ ] ぼかしではなく、復元できない塗りつぶしまたは切り抜きを使っている
- [ ] 背景の端末、通知、氏名、アイコンを確認した
